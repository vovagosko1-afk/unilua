# Hi, I’m @vovagosko1-afk 👋

I build Lua scripts for Roblox, including **Aero**, a universal script designed for the Delta executor.

## 🚀 Featured project: [Aero](https://github.com/vovagosko1-afk/unilua)

Aero is a single-file script with an interactive interface and configurable gameplay utilities.

### Features

- **Movement controls:** WalkSpeed, JumpPower, infinite jump, noclip, and fly
- **Visual options:** ESP and fullbright
- **Player tools:** Player list with health information and teleport controls
- **Adjustable settings:** Fly speed, FOV, aim smoothness, and team check
- **Touch-friendly interface:** Draggable, collapsible controls
- **Unload option:** Clean up the interface and restore script changes
- **And other**
